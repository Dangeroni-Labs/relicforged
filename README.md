# Relicforged

Relicforged adds a new relic-forging progression built around underused vanilla materials instead of new ores.

## Curseforge

[Relicforged - Curseforge](https://www.curseforge.com/minecraft/mc-mods/relicforged)

## Wiki & Recipes

[Dangeroni Labs - Relicforged](https://dangeroni-labs.vercel.app/mods/relicforged)

## Supported versions

| Minecraft | Forge |
| --- | --- |
| 1.20.1 | Yes |

Relicforged now available **only** for **Forge** loader and Minecraft **1.20.1**. No plans about porting to other mod loaders or versions.
